AULA 01 - HTML 5

Nesta aula abordaremos conceitos básicos da linguagem de marcação

HTML 5 é a versão mais moderna da linguagem HTML (HyperText Markup Language), utilizada para estruturar e organizar o conteúdo das páginas da internet. Ele permite criar elementos como textos, títulos, imagens, links, tabelas, formulários, vídeos e áudios.

O HTML 5 também oferece recursos para aplicações web modernas, como suporte nativo a áudio, vídeo, gráficos e formulários, reduzindo a necessidade de ferramentas externas. Geralmente, ele é utilizado em conjunto com CSS, responsável pela aparência da página, e JavaScript, responsável pela interação e comportamento dos elementos.
